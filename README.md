# Luce Chapel Bible Reading 현황 — 성경통독 종합 통계 대시보드

연세대학교회 성경통독(`ReadBible2026`) 프로젝트의 데이터베이스(Supabase)를 기반으로 구축된 **성경통독 종합 통계 및 현황 분석 웹 대시보드**입니다.

---

## 🌟 주요 기능 및 화면 구성 (v1.1 업데이트)

1. **상단 필터 (Control Bar)**
   - **시즌 선택 (ministry)**: 긴 시즌 명칭도 잘리지 않도록 콤보 박스 너비 대폭 확장
   - **기록 기준 기간**: 기준일자 선택 없이 해당 시즌 전체 완료 기록의 첫 기록일~마지막 기록일(KST)로 집계

2. **개요 (Overview KPI 카드 6종)**
   - **기간 / 일수**: `records` 테이블 최초 등록일 ~ 마지막 기록일 및 양 끝 날짜를 포함한 일수 기준 집계
   - **참여 인원수**: 해당 시즌 등록 인원 및 활동 인원
   - **전체 읽은 장수 / 1인당 일평균 / 구약·신약 완독률**

3. **일별 및 패턴 현황 (Charts)**
   - **일자별 차트**: 꺾은선에서 **막대그래프**로 변경, **TOP 5 최다 통독일을 황금색 막대로 시각적 강조**
   - **가장 많이 / 적게 읽은 날 TOP 5**: 순위 및 날짜 카드
   - **월별 통독량 차트**: 막대 상단에 **수치(장수) 직접 표시**
   - **요일별 통독 패턴 차트**: 막대 상단에 **수치(장수) 직접 표시**
   - **시간대별 통독 패턴 차트 (신규)**: 00시 ~ 23시 중 언제 성경을 많이 읽는지 24시간 패턴 시각화 (새벽기도/점심/취침 전 피크)

4. **조별(그룹별) 통독 현황**
   - 조별 총 읽은 장수 & 조별 1인당 평균 읽은 장수 (막대 우측 수치 라벨 표시)

5. **개인 통독 현황 (명예의 전당)**
   - 전체 완독 / 구약 완독 / 신약 완독 탭 전환, 실시간 검색, 메달 배지

## 🗄️ Supabase 데이터베이스 함수 등록

- 파일: `supabase_migration_stat_rpc.sql`
- Supabase 대시보드 > **SQL Editor**에 복사하여 **Run** 실행 시 실제 라이브 데이터로 즉시 전환됩니다.
- 순수 읽기 전용(STABLE) CTE 방식으로 작성되어 기존 운영 테이블이나 함수에 어떠한 부작용도 없습니다.


## ver 1.3.2026.1103

- 화면 순서: 개요(7개 지표) → 조별 완독률 → 개인 진도율 → 일별 현황.
- 전체 완독자 카드의 인원수·완독률·진행 막대 연결.
- 개인 진도율: 무기록자를 포함한 전체 참여자. 전체(1,189장)·구약(929장)·신약(260장) 탭, 진도율 내림차순, 이름/조 검색, 완독일자 표시.
- 일자별/최다·최소 TOP 5/요일별/시간대별: KST 기준 한 사람이 하루 **50장 이상** 등록하면 해당 사용자·날짜의 모든 기록 제외. 다른 사용자의 같은 날 기록은 유지.
- 요일별 평균: 제외 후 요일별 장수 합계 ÷ 최초 기록일~마지막 기록일의 해당 요일 일수. 무기록일 및 제외 후 0장인 날 포함.
- 개요·월별·조별·개인 진도율에는 대량 등록 포함. 조별 장수 차트는 일별 현황 하단 배치.
- 기준일 선택은 삭제. 기간·일수는 전체 완료 기록의 최초~최종 기록일(KST)로 계산하며, 일평균은 대량 등록 포함 전체 완료 장수 ÷ 전체 참여 인원 ÷ 기간 일수. 버전 표기는 `ver 1.3.2026.1103`.

### 적용

`index.html`과 함께 `supabase_migration_stat_rpc.sql`을 Supabase SQL Editor에서 실행해야 새 집계가 반영됩니다. 테이블 데이터 변경 없이 기존 RPC 함수를 교체합니다. 이전 RPC 응답에서는 업데이트 안내를 표시하고 새 기준을 적용할 수 없는 통계를 비워 둡니다.


### 기록 기준 기간 집계

- 시즌 내 전체 완료 기록을 사용하며 날짜 상한을 두지 않습니다. 무기록 시즌은 기간 없음, 0일, 일평균 0장입니다.
- 요일별 평균과 일자별 차트/TOP 5의 달력 범위도 최초~최종 기록일로 맞춥니다. 기간 중 0장인 날은 포함합니다.
- 일자별/TOP 5/요일별/시간대별은 기존처럼 1인 KST 하루 50장 이상 등록분을 제외합니다. 기간·개요·월별·조별·개인 진도율에는 포함합니다.
- `p_base_date`는 기존 RPC 호출과의 호환을 위해 남겨 두되 무시합니다. 앱은 더 이상 날짜 인자를 보내지 않습니다. `period_basis: record_span`이 없는 이전 SQL 응답에는 갱신 안내를 표시합니다.
- 적용 시 Supabase SQL Editor에서 통계 SQL 파일 전체를 실행해야 합니다.
